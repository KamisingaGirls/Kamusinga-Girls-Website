SEO FIXES FOR moigirlskamusinga.net
============================================================

Why: Google mostly decides what a page is about from its <title> line, then the
page headings and text. The Cardinal Otunga site puts the exact phrases people
search for (for example "Best Girls' School in Bungoma County") into its titles,
descriptions and page text. The Moi Girls titles did not contain those phrases.

HOW TO APPLY (about 15 minutes)
- In VS Code open each page. Press Ctrl+F, paste the FIND text, and select
  the whole line (or the sentence) it finds.
- Replace it with the NEW text underneath. Nothing else on the page changes.
- admissions.html: replace the whole file with the new one that came with this note.
- Then pull, commit and push as usual. Check each page's title in the browser tab.

NEED TO CHECK BEFORE ANYTHING ELSE (you are the only one who can)
-----------------------------------------------------------------
1. Open https://www.moigirlskamusinga.net/academics.html in a browser.
   - If the address bar changes to .../academics (no .html), your hosting is
     removing ".html". Then every page's canonical line should NOT end in .html.
     Example: change  https://www.moigirlskamusinga.net/academics.html
              to      https://www.moigirlskamusinga.net/academics
     and on the home page use  https://www.moigirlskamusinga.net/
     (a canonical that points to a different address than the page is served
     at sends Google mixed signals).
   - If it stays .html, leave the canonical lines as they are.
2. Open https://moigirlskamusinga.net (without www). It should jump to the www
   address, because the canonical lines all say www. If www jumps to the
   non-www address instead, tell me and we will change the canonicals.
3. Google Search Console > Performance. It lists the searches the school
   actually appears for, with impressions. If it shows 0 impressions, the
   pages are not being shown at all yet; if it shows impressions but low
   positions, the changes above plus links from other sites are what move it.
4. Ask the school to link to the website from the ACK diocese page, the Facebook
   page, any school directory and the Google Business Profile.

HONEST NOTE
-----------
Titles and page text are the part we can fix on the website itself, and they
are the visible difference from the Otunga site. Rankings also depend on how
many reputable sites link to the page and how long the site has existed, which
we cannot see for Otunga. Expect changes to show over days to weeks after
Google crawls the pages again, not instantly. After pushing, open Search
Console > URL inspection > Request indexing for the home and academics pages.
